# 온기 예약 사이트

전 지점 예약을 한곳에서 받는 홈페이지 예약 사이트입니다.

- **고객 화면 (`/`)**: "처음 오셨어요(체험)"와 "회원 예약"을 나눠서 받습니다.
  - 체험: 지점 → 날짜 → 시간 → 이름·연락처. 그 시간에 비어 있는 선생님 중 그날 일정이 가장 적은 분께 자동 배정됩니다.
  - 회원: 이름 + 연락처 뒷 4자리로 노션 회원 DB에서 확인한 뒤, 담당 선생님 빈 시간만 보여줍니다. 담당 선생님은 최근 90일 캘린더에서 이 회원 이름이 들어간 선생님으로 자동 추정합니다.
- **직원 화면 (`/staff`)**: 비밀번호로 들어가서 날짜별 전 지점 스케줄을 담당자별로 봅니다. 홈페이지로 들어온 예약은 ★ 표시.

## 데이터는 어디에 저장되나

사이트는 별도 DB가 없습니다. **각 선생님의 구글 캘린더가 곧 예약 장부**입니다.

- 예약이 확정되면 담당 선생님 구글 캘린더에 일정이 생깁니다. 노션 캘린더는 구글 캘린더를 보여주므로 그대로 보입니다.
- 일정 제목은 기존 '온기 예약 분석' 집계 규칙과 같습니다.
  - 체험: `이름+연락처뒷4자리 체험` (예: `홍길동5678 체험`)
  - 회원: `이름` (회차 `3/10`은 지금처럼 담당자가 붙입니다)
- 일정 메모에 `[홈페이지 예약]`, 지점, 연락처, 요청사항이 들어갑니다.
- 빈자리 계산: 선생님 캘린더에 '바쁨' 일정이 있으면 그 시간은 막힙니다. 지점 베드 수보다 일정이 많으면 막힙니다. 종일 일정은 제목에 `휴무/휴가/OFF/오프`가 있을 때만 그날을 막습니다.
- 노션 회원 DB는 **읽기만** 합니다. 회차·회원권 관리는 지금처럼 노션에서 합니다.

## 바꾸고 싶을 때

`src/config/branches.ts` 한 파일에서 지점, 베드 수, 선생님, 운영 시간(첫 타임·마지막 타임), 며칠 앞까지 열지, 최소 몇 시간 전까지 예약 가능한지, 체험가 문구를 바꿉니다. 청담점은 `open: false`로 '오픈 예정' 표시만 됩니다.

## 처음 설치 (한 번만)

### 1. 구글 캘린더 연결
1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 하나 만들고 **Google Calendar API**를 사용 설정합니다.
2. "IAM 및 관리자 → 서비스 계정"에서 서비스 계정을 만들고, **키 → JSON** 키를 내려받습니다.
3. 각 선생님이 자기 구글 캘린더 설정 → "특정 사용자와 공유"에 서비스 계정 이메일(`...@...iam.gserviceaccount.com`)을 추가하고 권한을 **"일정 변경"**으로 줍니다.
4. 각 선생님 캘린더 ID(보통 지메일 주소)를 `.env`의 `CAL_...` 칸에 넣습니다.

### 2. 노션 연결
1. [노션 통합 만들기](https://www.notion.so/profile/integrations)에서 내부 통합을 만들고 토큰을 복사해 `NOTION_TOKEN`에 넣습니다. 권한은 "콘텐츠 읽기"만 있으면 됩니다.
2. 지점별 회원 DB(회원 현황, 더프라이빗 회원현황, 회원현황(누적), 선릉 회원현황(누적)) 각각에서 `···` → **연결** → 만든 통합을 추가합니다.
3. DB ID는 `.env.example`에 현재 노션 DB로 미리 채워 두었습니다.

### 3. 배포 (Vercel 추천, 무료로 시작 가능)
1. 이 코드를 GitHub 저장소에 올립니다.
2. [vercel.com](https://vercel.com)에서 GitHub로 로그인 → 저장소 가져오기 → 배포.
3. Vercel 프로젝트 설정 → Environment Variables에 `.env.example`의 값들을 넣습니다. `GOOGLE_SERVICE_ACCOUNT_KEY`에는 JSON 키 파일 내용을 그대로 붙여넣습니다. `STAFF_PASSWORD`도 정합니다.
4. 원하는 도메인(예: `booking.온기도메인`)을 연결합니다.

## 내 컴퓨터에서 미리 보기

```bash
npm install
cp .env.example .env.local   # 값 채우기. 예시 데이터로만 보려면 DEMO_MODE=1
npm run dev                  # http://localhost:3000
```

`DEMO_MODE=1`이면 구글·노션 없이 예시 일정으로 돌아갑니다. 회원 예약은 `김온기 / 1234`로 확인합니다. 실제 운영에서는 반드시 비워 두세요.
